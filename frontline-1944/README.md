# Frontline 1944

A 3D WW2 soldier game that runs in the browser, built with Three.js.

## Files

- `index.html` is the page: menus, HUD and controls text.
- `style.css` is how the page looks.
- `game.js` is the game itself. The SETTINGS section at the top is the easiest place to start changing things.

## Run it

1. Open this folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and choose **Open with Live Server**.

The game opens in your browser and reloads every time you save a file.
You can also just double-click `index.html`. You need to be online, because Three.js loads from the internet.
